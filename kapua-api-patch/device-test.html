完整流程說明

步驟 1：管理員登入 Kapua（使用 kapua-sys 或 Google SSO）
步驟 2：CMS 產生一次性配對 Token
步驟 3：將 Scope ID + Token 輸入裝置
步驟 4：裝置上電後回傳 Token + Client ID 到 POST /v1/devicesNoAuth/getAndroidGatewayConfigByAccessToken
步驟 5：CMS 驗證 Token，對上後建立裝置並回傳原本的 Gateway Config XML

產生裝置配對 Token

系統會產生一組短效一次性 Token。裝置輸入後，回傳 Token 與自己的 Client ID，CMS 驗證成功才建立裝置。
